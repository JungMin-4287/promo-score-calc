# 승진점수 계산기

중등 교사의 **교감 자격연수 후보자 · 교감 승진 후보자 · 교장 자격연수 후보자 · 교장 승진 후보자** 서열점수를 계산하고, 앞으로 몇 해 근무했을 때 점수가 어떻게 오르는지 전망해 보는 웹 페이지입니다. 울산광역시교육청 「2026학년도 중등 교육공무원 승진 및 자격연수후보자 명부작성요령」과 평정프로그램 수식을 기준으로 합니다.

**사이트:** <https://jungmin-4287.github.io/promo-score-calc/> · 또는 [`index.html`](index.html) 한 파일을 내려받아 더블클릭해도 같은 화면이 열립니다(인터넷 연결 불필요).

## 쓰는 법

1. 사이트를 엽니다.
2. 오른쪽 위 **카드(PDF) 불러오기**에 NEIS **인사기록카드 출력 → 인사카드(전체)** PDF를 끌어다 놓으면 경력·연수·연구·가산점이 채워집니다. (직접 입력해도 됩니다.)
3. 카드에 없는 **근무성적**을 넣고, 읽은 뒤 알려 주는 **확인할 점**(연수의 집합·원격 구분, 한국사 요건, 올해 학년도 가산점 등)을 확인합니다. 오른쪽 점수와 각 탭은 **카드(입력한 실제 기록)만** 반영합니다.
4. **전망** 탭에서 앞으로 채울 수 있는 것 — 올해·앞으로 학년도의 부장·담임·농어촌·연구학교·학교폭력 실적과 추가 연수 시간, 예정 직무연수(예상 성적), 예정 연구대회·학위, 근무성적 가정값 — 을 넣어 **예상 점수**를 봅니다. 맨 위에서 **예상 평정기준일**을 앞으로 4~5년 뒤까지 고르거나 직접 적으면, 그날 명부 기준으로 카드 기준 점수와 예상 점수를 나란히 보여 줍니다(시간이 지나서 달라지는 몫과 입력한 예상으로 달라지는 몫을 나눠서). 그 해까지 학년도 칸이 필요하면 **학년도 칸 채우기**로 한꺼번에 만들고 해마다 고칩니다. 아래 표·그래프는 해마다 변화를 보여 줍니다. 예상 점수는 오른쪽 점수 카드 바로 아래에도 한 칸 더 나와서, 어느 탭에서든 스크롤 없이 함께 볼 수 있습니다.

화면마다 맨 위에 그 화면의 사용법이 있습니다.

## 개인정보

입력한 값과 불러온 PDF는 **이 브라우저 안에서만** 처리됩니다.

- 서버로 보내지 않습니다. (페이지 파일을 내려받는 요청만 있습니다.)
- 쿠키·웹 저장소·IndexedDB 등 **브라우저에 아무것도 저장하지 않습니다.** 새로 고치거나 닫으면 처음 상태로 돌아갑니다. 보관하려면 **입력값 저장**으로 파일을 받아 두세요.
- 페이지에 브라우저 보안 정책(CSP)이 들어 있어 **바깥으로 통신하는 것 자체가 막혀 있습니다**(`connect-src 'none'`, 외부 글꼴·스크립트 없음).
- PDF는 이 화면 안의 pdf.js로 읽어 표만 추려 낸 뒤 바로 버립니다.

직접 확인하는 방법:

- 브라우저 개발자도구(F12) → Network 탭을 연 채 PDF를 불러 보세요. 바깥 주소로 가는 요청이 생기지 않습니다. (브라우저 안에서 PDF 읽기 도구를 돌리는 `blob:` 항목은 통신이 아닙니다.)
- `index.html`의 앞부분 `<meta http-equiv="Content-Security-Policy" …>`를 읽어 보세요.
- 소스(`src/`)에서 `localStorage`, `fetch(`, `XMLHttpRequest`를 검색하면 나오지 않습니다.
  (`vendor/`의 pdf.js 라이브러리에는 URL로 PDF를 여는 기능의 코드가 들어 있지만 이 페이지는 호출하지 않고, 위 CSP가 막습니다.)

## 읽을 수 있는 PDF

NEIS 인사기록카드 PDF 두 가지 양식을 모두 읽습니다. 표 머리글의 글자(연수기간·시행기관·임용구분 …)로 열을, 가로선으로 줄을 찾기 때문에 쪽 배치가 달라도 됩니다.

- 「개인인사기록 〈구역〉」 제목이 붙은 구역별 출력(연수이수·가산점·연구실적·임용발령사항 …)
- 법정 양식 「인사카드」(1.신상사항 … 20.임용전 경력)

가져오는 것: 임용발령(근무 이력·보직교사) · 임용 전 군복무 · 자격연수 · 60시간 이상 직무연수 · 연도별 직무연수 시간 · 연구대회 입상 · 석·박사 학위 · 가산점(농어촌·특수여건·연구학교·담임·학교폭력 등) · 1급 정교사 취득일.
카드에 없는 것(근무성적, 한국사능력검정 요건, 연수의 집합/원격 구분, 아직 올라오지 않은 올해 학년도 분)은 비워 두고 알려 줍니다.

## 계산 범위와 검증

- 경력평정(기본·초과경력, 가·나·다 환산, 군복무·휴직) · 근무성적(유리한 3개 학년도) · 자격연수 · 직무연수(60시간 이상, 10년, 2021.1.1. 이전 원격 불인정) · 연구실적(연구대회·학위) · 공통·선택 가산점(기간 중복 불가 표 포함) · 한국사 요건 확인.
- 공식 평정프로그램(엑셀)과 22개 항목을 대조해 총점이 일치하는 것을 확인했고, 무작위로 만든 근무 기간 22건도 같은 결과가 나왔습니다. (공식 파일은 저장소에 넣지 않았습니다.)
- **참고용 계산입니다.** 실제 서열은 교육청이 확정한 명부를 따르며, 해마다 명부작성요령이 바뀔 수 있습니다.

알려진 한계: 순회교사 중 농어촌 소속 구분은 입력 칸이 없고, 직무연수 학점은 연도별 시간 합계로 계산합니다.

## 직접 빌드

Node.js 18 이상.

```bash
node build.js          # index.html 생성
node test/card_map_synth.js
```

`src/`의 소스를 한 파일(`index.html`)로 묶습니다. 구성: `engine.js`(계산) · `card.js`(PDF 표 복원) · `card-map.js`(표 → 입력값) · `app-*.js`(화면) · `vendor/`(pdf.js).
